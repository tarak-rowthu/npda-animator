# Formal Languages and Automata (FLA) Project

## N-PDA Animator

**Interactive Deterministic Pushdown Automaton Simulation and Language Recognition Tool**

The application code is located in the [`npda-animator`](./npda-animator/) directory.

### Quick Start

```bash
cd npda-animator
npm install
npm run dev
```

Run tests:
```bash
cd npda-animator
npm test
```

Build for production:
```bash
cd npda-animator
npm run build
```

See [`npda-animator/README.md`](./npda-animator/README.md) for full documentation, theory specifications, and architecture details.
